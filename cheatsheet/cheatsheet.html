1 Web, Browser, Begriffe

  • Internet = weltweites Netzwerk. WWW = ein Dienst darauf (Webseiten über HTTP), 1989 von Tim Berners-Lee am CERN erfunden, erste Website 1991.
  • HTML = HyperText Markup Language: Auszeichnungssprache für Struktur/Inhalt (keine Programmiersprache). CSS = Cascading Style Sheets: Darstellung, trennt Design vom Inhalt. JavaScript = Verhalten (nicht M101).
  • Browser (Chrome, Edge, Firefox, Safari): fordert Dateien beim Webserver an (HTTP/HTTPS = verschlüsselt), interpretiert HTML/CSS und stellt die Seite dar (rendern). Client-Server-Prinzip.
  • URL: https://www.zli.ch/kurse/index.html = Protokoll · Subdomain · Domain · Top-Level-Domain (.ch) · Pfad · Datei. DNS übersetzt Domain → IP-Adresse.
  • Webstandards: von W3C und WHATWG; Ziel: gleiche Darstellung in allen Browsern, Barrierefreiheit, Benutzerfreundlichkeit.
  • Endgeräte (Desktop/Tablet/Smartphone) unterscheiden sich in Auflösung, Bildschirmgrösse, Bedienung (Maus/Touch) und Bandbreite → kleine Bilder, viewport-Meta, flexible Layouts.

2 Projektablauf (Handlungsziele)

  1. Analyse: Ziel, Zielgruppe, Inhalte, Funktionen der Vorgabe.
  2. Sitemap = Struktur: welche Seiten, welche Inhalte wo, Hierarchie (M101: max. 3 Ebenen). Mockup/Wireframe = Layoutskizze inkl. Navigation (z. B. Adobe XD, Figma).
  3. Umsetzen mit HTML + CSS.
  4. Testen gegen die Vorgabe (Validator, Testprotokoll, Browser/Geräte).
  5. Veröffentlichen auf Webserver (FTP).

11 Urheberrecht, Bildrechte, Datenschutz

  • Für jede Verwendung eines fremden Werks braucht es eine Erlaubnis (Lizenz) des Rechteinhabers. Immer!
  • Geschützt: Werke = geistige Schöpfung mit individuellem Charakter (Texte, Musik, Bilder, Fotos, Filme, Software, Design). Nicht geschützt: Ideen, Konzepte, Methoden, reines Handwerk.
  • Schutz entsteht automatisch bei Erschaffung, keine Anmeldung/Register. © hat in der CH keine rechtliche Wirkung, nur Hinweis (empfohlen).
  • Dauer: 70 Jahre nach Tod des Urhebers, Software 50 J.; verwandte Schutzrechte (Interpreten, CD) 50 J. Gesetz: URG; zuständig: IGE.
  • Privatgebrauch erlaubt (inkl. Download/Streaming), Hochladen/Veröffentlichen nicht (auch ohne Gewinn). Zitat erlaubt: nicht länger als nötig, als Zitat kennzeichnen, Quelle nennen.
  • Recht am eigenen Bild: abgebildete Person entscheidet über Aufnahme und Veröffentlichung → Einwilligung einholen (Ausnahme: überwiegendes öffentliches Interesse, z. B. Menge an Veranstaltung). Im Zweifel fragen.
  • Creative Commons: BY = Namensnennung · NC = nicht kommerziell · ND = keine Bearbeitung · SA = Weitergabe unter gleichen Bedingungen · CC0 = frei. Gratis-Bildportale (Unsplash, Pixabay, Pexels): Bedingungen lesen, Urheber + Link nennen. Stock (iStock, Shutterstock): kostenpflichtige Lizenz.
  • KI-Bilder: ohne menschliche Schöpfung meist kein urheberrechtlicher Schutz; Nutzungsbedingungen des Tools beachten, keine geschützten Werke/echten Personen nachbilden.
  • Datenschutz (DSG): Personendaten nur nötig & zweckgebunden; Website mit Impressum und Datenschutzerklärung.

12 Testen & Barrierefreiheit

W3C Validator prüft Syntax gegen den Standard: HTML validator.w3.org, CSS jigsaw.w3.org/css-validator.

Testprotokoll (was, wie, Resultat, Massnahme). Technisch: Syntax HTML/CSS, DOCTYPE, Meta-Angaben (Autor, Beschreibung), nur von allen Browsern unterstützte Technologien, Bilder (Auflösung, Grösse, Format), Aktualität, Namenskonventionen. Gestaltung: einheitliche Schrift, Ausrichtung, Lesbarkeit/Kontrast, Bedienelemente (Links, Buttons), Layout/CI, HTML-fremde Inhalte (Typ+Grösse). In mehreren Browsern + Geräten testen (F12 Gerätemodus), alle Links klicken.

Barrierefreiheit: Textalternativen (alt), Kontraste & Farben, Skalierbarkeit (Zoom), Linearisierbarkeit (Reihenfolge im Code sinnvoll), Tastaturbedienung/Fokus, ARIA, Verständlichkeit & Navigation, strukturierte Inhalte (Semantik). Tools: Silktide-Extension, Accessibility-Checkliste (a11y.digitaldialog.swiss).

13 Veröffentlichen

  • Webhosting = Speicherplatz auf einem Webserver (+ Domain), z. B. Hostpoint.
  • FTP (File Transfer Protocol) überträgt Dateien zwischen Rechnern, unabhängig von Betriebssystem; auch Ordner anzeigen, umbenennen, löschen, Zugriffsrechte setzen.
  • Zugang: Server/Host, Benutzername, Passwort, Port (FTP 21). Sicher: SFTP (Port 22) / FTPS – normales FTP ist unverschlüsselt.
  • Werkzeuge: FTP-Client (FileZilla, Cyberduck), Browser-Add-on (fireFTP), WebFTP des Anbieters (umständlicher).
  • Vorher: index.html im Hauptordner, relative Pfade, Dateinamen klein, Bilder optimiert, validiert. Hochladen in Web-Ordner (z. B. public_html/httpdocs), danach online testen.

Breite (Standard content-box) = width + padding links/rechts + border links/rechts (+ margin). Mit box-sizing: border-box sind padding + border in width enthalten. Bsp: width 200 + padding 2×10 + border 2×1 = 222 px (border-box: 200).

Kurzschreibweise: margin: 10px alle · 10px 20px oben/unten · links/rechts · 5px 10px 15px oben · l/r · unten · 1px 2px 3px 4px oben rechts unten links (Uhrzeiger). border: 1px solid red (Breite Stil Farbe; Stil: solid dashed dotted double none). border-radius: 5px runde Ecken. margin: 0 auto + width = Block zentrieren. Vertikale margins fallen zusammen (der grössere zählt). Browser-Standards: body 8px margin, ul padding-left.
